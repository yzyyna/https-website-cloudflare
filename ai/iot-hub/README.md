# IoT Data Center · 实时数据调度控制台

> 纯 **HTML5 + CSS3 + 原生 JavaScript** 实现的单文件高性能海量物联网设备调度与监控控制台。
> 零外部依赖、零打包步骤，双击 `index.html` 即可在任意现代浏览器中离线秒开。

---

## 🌟 核心特性

1. **50,000+ 设备高性能虚拟滚动 (Virtual Scrolling)**
   - 采用视口偏移与幽灵容器（Phantom Container）技术，即便渲染 50,000+ 节点依然保持 60 FPS 流畅滚动与瞬时响应。
   - 针对窗口 Resize 与动态筛选自适应计算，集成零数据空状态（Empty State）优雅展示与快速重置。
2. **多维度层级树与折叠调度**
   - 支持华东、华北、华南等多区域、多城市与自定义设备群组的树状导航筛选。
   - 支持分组节点展开/收起切换记忆、防环路安全拖拽排布、快速新建/重命名分组。
3. **实时遥测数据模拟流与增量轻量刷新 (Mock WebSocket & Smart Diff)**
   - 内置事件总线与伪 WebSocket 引擎，高频模拟 5 万设备 CPU、温度、功率、延迟、电量等指标波动。
   - 采用增量感知刷新机制，非动态排序/过滤状态下仅更新可见行与详情图表，避免全量重排序抖动。
   - 修复 Canvas Tooltip 内存泄漏，详情抽屉遥测采用就地轻量同步，保障长时间运行平稳。
4. **实时告警中心联动与撤销恢复 (Undo/Redo)**
   - 包含多级别告警面板、5 分钟自动去重、告警条目一键快速定位并聚焦目标设备抽屉。
   - 内置操作历史记录栈，支持告警操作、分组操作与批量任务的撤销与重做。
5. **快捷命令面板 (Command Palette)**
   - 支持快捷键 `Cmd+K` 或 `Ctrl+K` 快速呼出全局指令菜单（搜索、创建分组、暂停遥测、导出数据等）。
   - 按 `/` 快捷键瞬间聚焦全局设备搜索框，按 `ESC` 关闭抽屉与弹窗。
6. **数据导入与导出**
   - 支持一键导出筛选设备为标准 CSV 或 JSON 格式文件。
   - 支持上传 JSON 数据进行客户端模式校验、错误提示及批量合并导入。
7. **深浅色主题自由切换**
   - 内置暗黑极客模式（Dark）与明亮办公模式（Light），一键无缝切换并自动持久化。

## 🚀 启动与运行

- **双击运行**：直接在文件管理器中双击 `index.html`。
- **本地服务（可选）**：
  ```bash
  python3 -m http.server 8080
  # 浏览器访问 http://localhost:8080
  ```

## ⌨️ 常用快捷键

| 快捷键 | 功能 |
|---|---|
| `Cmd + K` / `Ctrl + K` | 呼出全局快捷命令面板 |
| `/` | 快速定位并聚焦顶部设备搜索框 |
| `Escape` | 关闭抽屉详情、日志弹窗或快捷面板 |
