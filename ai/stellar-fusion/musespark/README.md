# STELLAR CORE · 3D 星际聚变能源监控中心

> 纯 **HTML5 + CSS3 + 原生 WebGL 2.0 (GLSL ES 3.00)** 实现的单文件大型 3D 星际聚变与行星能源传输监控中心。
> 零外部依赖库（无 Three.js / Babylon.js），采用纯代码手写 GLSL 着色器、FBO 泛光合成与射线交互系统，离线即开即用。

---

## 🌟 核心特性与架构

1. **双重实现对比展示**
   - `index.html`（**主入口**）：**STELLAR CORE 终极优化版**。基于对标方案进一步深度重构，融合独有的青蓝/紫曜双色能量场调色板、FBO 降级自适应容灾、引力粒子扰动以及增强型响应式抽屉。
   - `IndexGLM.html`（**标杆参考版**）：HELIOS-7 经典参考实现，用于横向技术对标与对比评估。
2. **Procedural 3D 聚变核心与动态天体**
   - **Stellar Fusion Core**：三轴差速磁约束光环、能量光晕、动态脉冲外壳与 12 股高能等离子体流。
   - **地球光照模型**：大气散射光环、昼夜面过渡着色器。
   - **星际管网网络**：30 个全球枢纽城市节点、18 条长途高能骨干干线、4 座近地轨道空间站与 3 颗同步通信中继卫星。
3. **多级 FBO 后处理渲染管线 (Post-Processing)**
   - 提取高亮区域 → 2~3 次双向高斯模糊降采样 → 最终全屏混合合成。
   - 支持辉光发光（Glow）、色散色差（Chromatic Aberration）、阴极射线扫描线（Scanline）与径向暗角（Vignette）。
4. **自适应性能看门狗与动态降级**
   - 监听屏幕 DPR 与像素负载，高分辨率屏幕自适应缩放。
   - 连续检测到丢帧（FPS < 24）时自动降低着色器迭代深度与模糊 Pass 级别，确保全天候持续稳定运行。
5. **HUD 仪表与交互**
   - 浮动毛玻璃面板、四角实时遥测（磁通量、护盾完整度、GPU 性能、瞬时总功率）。
   - 5 款原生 Canvas 高帧率图表，支持实时悬停十字准星与时间旅行回放。

## 🚀 启动与运行

- **直接打开**：双击 `index.html`（推荐使用 Chrome / Edge / Safari 等支持 WebGL 2.0 的现代浏览器）。
- **对比查看**：双击 `IndexGLM.html` 可横向查看经典版实现效果。
- **本地服务（可选）**：
  ```bash
  python3 -m http.server 8080
  # 访问 http://localhost:8080
  ```
