# 《404 之前：互联网考古馆》

一个带你横向穿越 1998、2003、2008、2012、2024、2099 六个互联网时代的单页互动遗址体验项目。

## 🌟 核心特性

- **纯原生零依赖**：单页纯 HTML5 / CSS3 / ES6+ JavaScript，免构建、无需后端、无需引入外部字体或图片库。
- **全平台离线运行**：直接在现代浏览器（Chrome、Edge、Safari、Firefox）中双击打开 `index.html` 即可完整体验。
- **Web Audio 纯合成音效**：零音频文件依赖，代码实时合成 1998 DTMF 拨号、Modem 握手嘶嘶声、2003 八音盒 MIDI 琶音、空间水滴声、碎片磁吸与大和弦。默认完全静音，支持右上角一键开启。
- **6 大时代互动展厅**：
  1. **1998 拨号接入室**：CRT 扫描线、Win98 对话框、Modem 状态灯联动、不要点.exe 像素猫彩蛋。
  2. **2003 个人主页花园**：千禧审美、跑马灯、艺术字、心情切换日记、访客留言簿、计数器暴涨彩蛋。
  3. **2008 深夜论坛**：经典天涯猫扑蓝白版式、引用回复、网络延迟发帖、幽灵在线人数彩蛋。
  4. **2012 青春空间**：梦幻皮肤切换、装扮值增长触发流星雨、说说发布带机型小尾巴、匿名访客彩蛋。
  5. **2024 算法走廊**：视线停留、点赞/划走实时计算理解度，触发算法透明度报告彩蛋与跃迁虫洞。
  6. **2099 网页遗址修复中心**：6 块历史遗迹碎片对位拼图，严格时代匹配检测与弹回动效，集齐解锁终极档案并可导出离线纪念册。
- **数据持久化与安全**：`localStorage` 自动记录全部发掘进度与内容，全面防范 XSS 脚本注入。

## 🎮 操作指南

- **键盘导航**：方向键 `←` / `→`、`PageUp` / `PageDown` 快速切换年代。
- **鼠标交互**：支持鼠标横向滚轮（智能避让长内容垂直浏览）、按住鼠标左键横向拖拽抓取。
- **时间轴定位**：点击底部 6 个年份节点直接跳转。

## 🛠️ 构建与维护

源码按模块与年代拆分在 `js/` 与 `js/eras/` 目录下。若对源码进行了修改，可直接运行：

```bash
node build.js
```

该脚本会将源码安全打包更新至 `js/app.bundle.js`，保证在 `file://` 协议下本地免服务器直接运行。
