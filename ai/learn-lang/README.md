# LinguaJourney · 沉浸式多语种学习平台

> 纯 HTML5 / CSS3 / JavaScript 单页应用（SPA），无需 Node.js、Vite 或构建打包工具，双击 `index.html` 即可在任意浏览器中流畅运行。

---

## 🌟 项目简介

LinguaJourney 是一个现代化的多语种语言学习平台前端应用，集成了学习路径规划、3D 交互记忆闪卡、学习活跃度可视化图表、社区互动交流及学霸排行榜等完整学习体验。

### 核心特性

1. **响应式架构**
   - 桌面端：左侧持久化固定导航边栏 + 顶部用户卡片
   - 移动端：底部浮动导航栏，适配触摸与多种屏幕宽度
2. **六大功能视图**
   - 🏠 **首页 (Home)**：多语种标签（英语、日语、韩语、法语、德语、西语）、平台特色矩阵展示与新手引导。
   - 📊 **学习中心 (Dashboard)**：连卡天数徽章、等级与经验值（EXP）进度条、个性化核心推荐课、近 7 天学习活跃度 SVG 折线趋势图、今日任务清单。
   - 📚 **课程大纲 (Course)**：职场商务沟通中级课程，共 5 个模块（破冰、例会、邮件、听力、谈判）；当前仅「破冰」模块可完成，其余模块的解锁与完成逻辑尚未实现，点击时会给出前置提示。
   - 🃏 **3D 记忆闪卡 (Learn)**：核心词汇 3D 翻转卡片（CSS 3D `preserve-3d` + `rotateY` 真实透视）、Web Speech API 原生单词语音朗读、进度指示器、完成结算 +50 EXP 奖励。
   - 💬 **社区交流 (Community)**：实时发布学习动态、点赞与评论互动、学霸经验排行榜、每周挑战打卡。
   - 👤 **学员登录 (Login)**：输入昵称实时生成个性化矢量头像（本地纯 SVG 生成器）、登录态本地持久化。
3. **本地状态持久化**
   - 基于 `localStorage` 自动存储用户身份、等级、经验值、已完成模块及社区动态，刷新页面数据不丢失。
   - 存储键为 `linguajourney_state_v1`；若不存在则只读回退到旧键 `linguajourney_state`（不删除旧数据），之后仅写入 v1 键。
   - 读取时对昵称、头像、经验值、模块 ID、动态内容做类型白名单与数值清洗；`localStorage` 不可用或配额超限时降级为内存状态并给出一次性提示。
4. **站内提示与降级**
   - 操作反馈使用非阻塞的底部 toast（替代 `alert`）。
   - 剪贴板 API 不可用或失败时，自动回退到 `execCommand('copy')`；仍失败则提示用户手动复制地址栏链接。

## 🚀 快速启动

- **直接打开**：双击 `index.html` 或在浏览器中右键选择通过 Chrome / Safari / Edge 打开。
- **本地服务（可选）**：
  ```bash
  # Python 简易服务
  python3 -m http.server 8080
  # 打开 http://localhost:8080
  ```

## 🛠 技术实现细节

- **纯原生技术栈**：纯 HTML5 + 纯 CSS3 + 原生 ES6+ JavaScript。
- **无外置构建依赖**：移除了所有的 `npm`、`vite`、`react`、`typescript` 等重型依赖及 180MB+ 的 `node_modules` 目录，轻量化部署。
- **语音合成**：内置浏览器 `window.speechSynthesis` API 实现纯本地原生发音，无需第三方语音接口。
