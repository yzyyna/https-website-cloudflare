# 3D Tank Clash · 钢铁风暴 3D 坦克大战

纯 **HTML5 + CSS3 + 原生 JavaScript + WebGL 1.0 + Web Audio API** 实现的经典《坦克大战》现代化 3D 进化版。
极简免构建架构（仅包含自包含的 `index.html` 与 SVG 资源），零第三方 npm 库依赖，零打包步骤，双击 `index.html` 即可 100% 离线流畅游玩。

---

## 🎮 游戏核心特色

1. **三维战场与多视角自由切换**：
   - 经典 3D 俯瞰等轴视角（Isometric 3D，兼顾全局战略与立体质感）
   - 过肩追尾沉浸式视角（Third-Person Chase，强烈的射击与驾驶代入感）
   - 战术沙盘顶视视角（TopDown 3D）
   - 按键盘 `V` 键或移动端视角按钮实时无缝切换。

2. **多兵种装甲作战体系**：
   - **玩家战车**：支持 4 级科技晋升（轻装侦察型 → 突击加农型 → 双联装重炮型 → 磁暴等离子毁灭者）。
   - **侦察轻坦（Scout）**：速度快、机动灵活。
   - **突击装甲车（Speed）**：高速机动突袭司令部。
   - **重型加农坦（Heavy）**：高装甲高血量，发射双联重炮。
   - **高能狙击坦（Sniper）**：远距离激光贯穿打击与弹道预警。
   - **终极泰坦巨兽（Titan Boss）**：第 5 关决战巨型 BOSS，拥有三向扩散弹幕与超高护甲。

3. **丰富战地战术道具与打砖块爆宝**：
   - 🔩 **合金旋转钻头**：车头装载 3D 旋转钻头，直接冲撞碾碎一切砖石与钢铁墙体，近战重创敌军
   - 🚀 **追踪飞弹**：发射自动锁定并追踪最近敌人的高能导弹
   - 🔫 **暴风加特林**：超高射速加特林机枪，每秒 12 发暴风扫射
   - 🛸 **护航僚机**：左右升空 2 架 3D 悬浮僚机自动索敌开火
   - ⭐ **星徽晋升**：升级战车主炮、射速与弹药形态
   - 🛡️ **能量护盾**：全向无敌护盾，抵挡一切物理与激光穿透
   - 💣 **战术核爆**：引爆全图，瞬间消灭所有常规敌军
   - ⏱️ **时间定格**：EMP 瘫痪所有敌方单位 10 秒
   - 🔨 **铁壁防线**：基地老鹰司令部周围瞬间换装坚固合金钢甲 20 秒
   - ❤️ **战地抢修**：满血恢复装甲
   - ⚡ **过载引擎**：移动速度与主炮装填速度加倍
   - 🧱 **打砖块爆道具**：轰碎任意砖墙有几率直接开出强力战备道具箱！

4. **5 大精心设计战区与完整通关战役**：
   - **第 1 关 · 绿野先锋**：教学与基础装甲排突围
   - **第 2 关 · 水网要塞**：涉水防守与丛林伏击
   - **第 3 关 · 钢铁迷宫**：极地冰面滑行与激光狙击
   - **第 4 关 · 熔岩前线**：全兵种协同反扑
   - **第 5 关 · 决战泰坦要塞**：终极泰坦重装巨兽 BOSS 战，击败后触发通关凯旋盛典

5. **纯代码程序化 Web Audio 合成音效**：
   - 包含主炮开火轰鸣、激光呼啸、砖块碎裂、装甲跳弹、深沉 3D 爆炸、道具拾取、警报与胜利凯旋交响乐。

## ⌨️ 操作指南

| 键盘按键 | 移动端触屏 | 操作功能 |
|---|---|---|
| `W` `A` `S` `D` / 方向键 | 左下角虚拟摇杆 | 控制战车车体移动与转向 |
| 鼠标左键 / `Space` / `J` | 右下角开火按钮 💥 | 主炮开火射击 |
| `Shift` | 摇杆全推 | 推进加速 / 战车漂移 |
| `V` | 视角按钮 🎥 | 切换 3D 等轴 / 追尾 / 沙盘视角 |
| `P` / `Escape` | 顶栏暂停按钮 | 暂停战局 / 打开作战菜单 |

## 🛠️ 技术架构亮点

- **自研微型 WebGL 3D 渲染器**：包含矩阵运算、Phong 光照着色器、点光源动态爆炸反光、法线计算与深度测试。
- **高性能物理与网格碰撞检测**：网格瓦片分轴碰撞，防止穿墙穿透；子弹射线碰撞与四散碎片粒子系统。
- **全平台响应式适配**：自动识别移动端并激活触屏虚拟摇杆与动作按钮，桌面端支持平滑键鼠控制。
