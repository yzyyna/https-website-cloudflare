# 鹈鹕踩单车 · 六模型同题对标（pelican-bicycle）

同一段提示词，交给六个模型各写一个**单文件、自包含、双击即可离线运行**的 HTML 页面。入口页可切换查看、盲评打分、揭晓榜单。

## 运行

- 双击本目录 `index.html`（推荐，纯 `file://` 也能跑）。
- 或从根门户卡片「鹈鹕踩单车 · 六模型同题对标」进入。
- 各版本也可单独双击：`glm/index.html`、`kimi/index.html`、`step/index.html`、`minimax/index.html`、`deepseek/index.html`、`gemini-3.8-flash/index.html`。

## 同题提示词

```text
请写一个单文件、自包含、双击即可离线运行的 HTML 页面，主题是「一只鹈鹕骑自行车」，把完整代码写入仓库文件。

硬性要求：
1. 只写这一个文件，不创建或修改其他文件，不启动本地服务，不安装依赖。
2. 零外部资源：禁止 CDN、外链脚本/样式/字体/图片/音频，禁止 fetch/XHR，禁止任何 http(s) 地址；自行车与鹈鹕必须程序化绘制（Canvas 2D、内联 SVG、CSS 任选）。
3. 真实骑行感：车轮转动、曲柄与蹬腿同步、身体随路面上下颠簸、背景视差滚动，让人一眼看出在骑车而不是摆拍。
4. 至少 3 个可操作交互或状态切换，例如加速/减速/刹车、坡度或风阻、昼夜或天气切换、合成的车铃或鸟鸣、视角切换；键盘与鼠标/触摸都能触发主要交互。
5. 移动端适配：viewport-fit=cover、安全区 env(safe-area-inset-*)、可点击目标不小于 44px；动画用 requestAnimationFrame；Canvas 或 AudioContext 不可用时降级提示而不是白屏报错。
6. 中文界面；代码整洁、关键逻辑有注释；页面打开 3 秒内能直接看懂在发生什么。
7. 直接动手写完整实现，不要把代码正文回传给我。完成后返回 tech、features、note。
```

## 入口页功能

- **切换查看**：顶部标签 / 快捷键 `1`–`6`、`←` `→` 切换，hash 路由（`#glm` 刷新不丢）。
- **盲评模式**：六个版本以 A–F 匿名展示，顺序按随机种子固定，避免位置偏差；给任意版本打分后点「署名模式」或直接切换即可揭晓。
- **我的评分**：1–5 星，记录在本机 localStorage（键 `pelican-bicycle:state:v1`），不上传、不跨设备。
- **桌面 / 手机**：预览区可切换 400px 手机宽度，检查各版响应式实现。
- **全屏 / 新窗口**：`F` 键或按钮进入全屏；新窗口直接打开该版原始页面。

## 自动检查口径

生成流程对每个文件执行确定性检查：存在 `<html>` 根元素、体积下限、无外链 `src`/`href`、无 `@import`、无外链 `url()`。检查不通过会退回同一模型修复（最多两轮）。

## 修复记录

静态检查通过后，又用 headless Chrome 逐版加载并抓取控制台，发现并修复了两处渲染缺陷（均由写出原代码的同一模型完成，未做人工润色）：

- **Step 版**：`drawSunMoon()` 被无参调用，半径 `undefined` 使每帧 `createRadialGradient` 抛 `non-finite`，rAF 主循环第一帧即中断，画布全黑只剩 HUD。修复为 `drawSunMoon(r)` + 半径缺省兜底，并校正黄昏日轮被山体遮挡的问题。
- **Kimi 版**：`groundY()` 二分区间（`[-12, 0]`）远小于地形函数量程（约 ±112），饱和后车身倾角 `atan2` 得 ±π，整车倒挂；同时前后轮定义与鹈鹕朝向相反。修复为按候选倾角求最小二乘落地高度、互换前后轮、相机开局直接落到目标位置。

其余四版首轮即通过控制台检查。

## 已知限制

- 评分与盲评顺序仅保存在当前浏览器，换设备不共享。
- `file://` 下各版 iframe 均按同源加载，个别浏览器若禁用了本地 iframe，请用「新窗口打开」直接查看。
- 各版为模型原始产出，代码风格、体积与功能完整度差异较大，属于对标本身要展示的内容；除兼容性 Bug 外不做人工润色，以免破坏公平性。
