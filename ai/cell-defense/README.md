## 🔬 游戏玩法与核心机制

在《细胞防线》中，玩家化身为宿主人体免疫系统的微观总指挥。病原体正顺着毛细血管对重要脏器发起多波次急性感染，你必须调兵遣将，构筑生物活性防线：

1. **真实阿米巴伪足吞噬与消化循环（Phagocytosis Cycle）**：
   - 巨噬细胞不是冰冷的炮塔，而是活体阿米巴变形体。它能伸出柔性伪足卷入流感病毒或病菌，在体内的液泡中用溶酶体酸液消化分解，产出大量 **ATP（建造能量）** 和 **RNA 片段（基因密码子）**。
2. **基因拖拽融合升阶（Merge & Morph）**：
   - 将两只同类型且同阶的细胞**拖拽重叠**，触发细胞核质融合，直接突变升级为二阶/三阶特种终极生物体，火力与范围爆发式增长。
3. **心跳微流与顺流抗体水雷**：
   - 整个战局伴随宿主心跳节律（每 6 秒一次舒张收缩），血液微流会顺流推进一切游离微粒。B 淋巴细胞释放的 Y 型抗体随流飘动，形成动态水雷区锁死病原体。
4. **神谕神经主动技能**：
   - **肾上腺素激增 (Adrenaline)**：5 秒内全场细胞代谢与吞噬速度翻倍。
   - **局部高热发烧 (Fever)**：在微血管引发 40℃ 局部高温，病毒移动速度暴降 65% 并破除保护层。
   - **干扰素修补 (Interferon)**：紧急修补宿主破损组织，恢复生命值。
5. **局内轻度 Rogue 基因进化**：
   - 击退感染波次可激发造血干细胞基因剪接，从三项随机变异协议中选择一项永久增强战斗力。

## 🚀 运行与操作说明

### 1. 运行方式
- **双击即玩**：直接双击当前目录下的 `index.html`，在任意现代浏览器中即可完整体验。
- **本地服务运行**：在项目根目录启动静态服务：
  ```bash
  python3 -m http.server 8080
  # 访问 http://localhost:8080/cell-defense/
  ```

### 2. 操作指南
- **安放细胞**：点击底栏细胞卡片选中后，点击血管旁**发光的虚线基座**即可放置；放置前会有跟随指针的预览虚影与十字准星，红色表示该位置放不下。
- **撤销建造**：**长按任意细胞 0.4 秒**（按住会出现红色环形进度）即可移除，并**全额退还 ATP**。
- **加速消化**：轻点体内有消化泡的巨噬细胞，可手动加速溶酶体分解。
- **拖拽融合**：按住场上已有细胞拖到另一只同名同阶细胞上重叠松手，即可合成升阶（触屏带磁吸辅助，靠近自动吸附）。
- **释放神谕**：点击右侧技能栏（PC 快捷键 `Q`/`W`/`E`），释放肾上腺素、局部发热或干扰素。
- **PC 快捷键**：`1`–`5` 选择细胞、`空格` 暂停、`Esc` 取消当前选中。
- **多端适配**：触屏目标 ≥44px、单行顶部 HUD、双行底部操作台；血管与基座槽位按「安全可视区」自动排布，永不被 HUD 或底栏遮挡。

## 🛠️ 技术架构与特性

- **纯原生零依赖**：无任何 NPM 包、无打包构建工具、无外部 CDN、无在线素材外链；5 个普通 `<script>` 按依赖序加载，双击 `index.html` 即玩。
- **纯代码 Web Audio 合成**：吞咽水泡声、心跳双音节（Lub-Dub）、溶菌酸腐蚀、穿孔素爆破皆由纯代码数学振荡器调制生成；`AudioContext` 不可用时静默降级不抛异常。
- **自适应视网膜屏**：Canvas 自动适配 `window.devicePixelRatio`（限制 ≤2），使用 `setTransform` 避免重复缩放累积，粒子/弹体/飘字均设全局上限。
- **安全可视区布局**：血管路径与细胞基座由脚本按实测 HUD/底栏占位生成，槽位沿管壁交替分布并经松弛迭代保证最小间距，横竖屏切换、窗口缩放后自动重排并把已有细胞重绑到新槽位。
- **视口兜底轮询**：部分内嵌面板不派发 `resize` 事件，项目用 `ResizeObserver` + 自调度 `setTimeout` 链 + 指针按下时强制校正，保证「点哪儿放哪儿」。
- **单元测试**：`node cell-defense/test.js` 覆盖音频容灾、细胞配置、融合升阶、病原体抗性、存档校验恢复、引导去重、濒危告警、拖拽回弹、基座布局、长按退款与手势阈值。
