# MiniCraft · 方块世界

纯 **HTML + CSS + JavaScript + WebGL** 实现的类《我的世界》3D 沙盒游戏。
零依赖、零外部资源（贴图与音效全部程序化生成），下载后双击 `index.html` 即可离线游玩。

## 运行方式

- **最简单**：双击 `index.html`（Chrome / Edge / Safari / Firefox 均可）。
- 或起本地静态服务（可选）：
  ```bash
  cd block-game
  python3 -m http.server 8123
  # 浏览器打开 http://localhost:8123
  ```

## 玩法内容

- **收集与合成**：挖树得原木 → 合成木板/木镐；挖矿得煤/铁/金/钻石 → 合成火把、铁镐、钻石镐、TNT、萤石、书架、工作台、玻璃、砖块（背包面板右侧点击即合成，材料不足自动置灰）。
- **照明系统**：洞穴越深越暗；火把/萤石是真实点光源（8 格衰减），夜里也亮堂——探矿请带火把。
- **矿石分布**：煤（常见）、铁（y≤36）、金（y≤24）、钻石（y≤14），越深越稀有。
- **TNT**：右键点燃 → 引线闪烁 2.5 秒 → 爆炸炸坑 + 冲击波击飞玩家，**邻近 TNT 会连锁引爆**。
- **昼夜循环**：4 分钟一天，日出/白昼/黄昏/星空，太阳月亮绕天运动。
- **世界**：种子化无限地形——草原（有虞美人）、丘陵、雪山、湖泊、沙滩、洞穴、树木；跨区块生成一致。
- **氛围**：逐面光照 + 顶点 AO + 体素云 + 雾效 + 水下滤镜 + 破坏粒子 + 程序化音效（脚步/入水/爆炸/合成）。
- **存档**：方块改动、玩家位置、背包、统计（挖掘/建造数）、设置自动存 localStorage（每 12 秒 + 暂停/关页时）。
- **第一人称手持**：当前方块/工具以等距视角显示，走路摆动、挖掘挥动。

## 技术要点

- 自写 WebGL1 渲染器：区块化懒加载（16×16×64），每区块两套网格（不透明/半透明），
  隐藏面剔除 + DDA 体素射线 + 分轴分步 AABB 物理防穿透 + 背面视锥粗剔除。
- 双通道光照：顶点携带"天空光 × 日照强度"与"方块自发光"两个分量，着色器取 max——火把夜里依旧明亮。
- 贴图图集（30+ 程序化 tile）、云层网格、星空点精灵均由 Canvas/代码生成；音效由 WebAudio 合成。
- rAF 饥饿看门狗：浏览器后台不渲染帧时以 4Hz 兜底推进，保证后台自动存档不冻结。
- `window.MCX` 暴露调试接口（teleport / mine / step / setTime 等），便于自动化测试，不影响游戏。

## 已知限制

- 水为静态（不模拟流动）；无生物、无饥饿值——定位是沙盒建造玩法。
- 爆炸破坏的方块不掉落物品；火把/花可用中键选取但placing 后为十字面片。
- 渲染距离默认 4 区块，低配机器可在暂停菜单调小。
